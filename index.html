A single challenge URL starts a continuous process, from understanding the rules to preparing the submission.

Seven connected phases

Research, ideas, selection, technical plan, implementation, tests, submission docs.

Understand the challenge

Read the rules, requirements, and judging criteria. Research the problem, explore ideas, and choose what to build.

Make it work

Turn the chosen approach into a technical plan and working code. Run tests, check the result, and iterate.

Bring it together

Prepare the project and its submission documents, so the finished work is ready to present and explore.

The agent is
the contestant.

0xClaw entered a hackathon entirely by itself. It was handed a single URL: the hackathon registration page. It researched the requirements, generated ideas, selected an approach, and produced a technical plan.

It then implemented a working project, ran tests, and wrote the full submission documents—without a human writing a line of code for that run.
